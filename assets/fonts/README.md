# Inter

Unmodified static TTF fonts from the official
[Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), extracted from
`Inter-4.1.zip/extras/ttf/`.

Bundled weights: 400, 500, 600, 700, and 800. The copyright and SIL Open Font License
1.1 are retained in `OFL-Inter.txt`, which is also packaged as an application asset.
Fonts are local assets, not runtime requests or a font-service dependency.
